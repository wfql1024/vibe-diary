# decisions — 为什么这么定

> 用途：记录有分歧、有取舍的技术决策（背景 / 选项 / 选择 / 理由），将来翻旧账时看这里。
> 不写什么：不写"现在是什么样"（去 facts.md）、不写踩坑过程（去 lessons.md）。
> 更新方式：追加；未定的标 `状态: 待定`，定稿后标 `状态: 已定`。

## D1 tag_links 改成有向存储

- 背景：v1 为"天然去重"建表时加了 `CHECK (source_tag_id < target_tag_id)`，前端插入前也排了序。
- 问题：方向被吃掉，用户拖 `生活 → 健身` 会被存成 `健身 → 生活`，箭头和检索都反了。
- 选择：migration 002 重建表去掉 CHECK，插入/删除/合并一律保留原方向；已有的边原样搬过去（旧行方向可能已被掰反，需重画）。
- 理由：关系语义本身就是有向的（A→B 表示"搜 B 也带出 A"），去重应该靠主键而不是靠排序。
- 状态: 已定

## D2 关系语义 = 传递闭包，允许成环

- 背景：用户明确"标签没有等级，靠连接性表达分类""成环在效果上等于这几个标签是一回事""不要让寻找变成无限循环引用"。
- 选择：递归 CTE（`UNION` 而非 `UNION ALL`）+ `EXISTS` 判定。
- 理由：`UNION` 自带去重，成环自动终止；`EXISTS` 保证一条记录只出现一次，不会因为"自身命中 + 关系命中共存"被重复计数。
- 状态: 已定

## D3 关系只影响检索，永不回写记录

- 选择：`entry_tags` 只在标签增删改/手动编辑时变化；检索用查询期扩展。
- 理由：用户的明确原则"标签之间权限互相独立，对单个标签的管理只影响这个标签本身"。
- 状态: 已定

## D4 计数分两个口径：usage（自身）与 reach（含关系）

- 选择：侧栏与画布显示 `总数(自身+外部)`；排序用 reach；筛选结果数与之对齐。
- 理由：用户指出"排序依据应该是含外部连接的总数"，且"点标签的命中数必须等于标签上的数字"。
- 状态: 已定

## D5 双向关系在画布上合并成一条双线

- 背景：A→B 与 B→A 同时存在时，两条线重叠、箭头互相打架。
- 选择：渲染层按无序对合并成**两条平行细线**（无箭头），点击删除时两个方向一起删；布局里弹簧只算一次（避免吸力翻倍）。
- 理由：用户"本质还是一条线，只是双线效果""删除就直接删整条"。
- 状态: 已定

## D6 画布布局：力导向 + 硬约束 + 冻结

- 背景：纯力平衡在稠密图（40+ 条关系）里永远收敛不了，表现为"一直缓慢旋转/蠕动"；线还会被圆压住、互相交叉。
- 选择：
  1. 位置式逐帧松弛 + 全局降温（260 帧后 damp=0）+ 连续 5 帧 <0.12px 停；
  2. 最后一道「硬性分离」pass，把最小间隙变成硬约束（边界夹取 / 交叉翻转都破不掉）；
  3. 相连两圆最小间隙 `LINKED_GAP=34`，保证连线看得见；
  4. 线-圆、线-线都有斥力，绘制层再用贝塞尔绕行兜底；
  5. 重力各向异性（纵向 ×2.2）铺满矩形画布，而不是团成正圆。
- 理由：用户的四条要求——"不能生硬""尽快稳定，不能缓慢旋转""线不能被圆盖住""不能交叉"。
- 状态: 已定

## D7 搜索框用 GitHub 风格 `tag:` 语法

- 选择：点侧栏标签 = 插入/移除 `tag:名称` token；多个 token 之间 AND；`tag:` 先精确名，找不到才 LIKE；其余文字做正文/标题/日期匹配。
- 理由：用户"筛选条件应当直接在搜索框里体现，像 repo:/owner: 那样"。
- 状态: 已定

## D8 记录页不再展示标签关系清单

- 选择：关系只在「标签画布」里看与改；侧栏只留标签云（全量、按 reach 排序）。
- 理由：用户"记录页面标签关系就不用展示出来了；标签应当将所有都显示出来"。
- 状态: 已定

## D9 导入脚本默认不生成关系

- 选择：`scripts/import-json.mjs` 默认只导记录与标签；关系要靠人工在画布上连线，想自动铺一遍加 `--with-links`。
- 理由：早期的"同一天共同出现"自动连边产生 267 条噪声关系，用户要求全部清空。
- 状态: 已定

## D10 本机工具链与网络方案

- Rust 装 D 盘（`RUSTUP_HOME` / `CARGO_HOME` 用户变量）；rustup 下载走清华 http 镜像；cargo 索引走清华 http 稀疏索引；crates 本体用 `scripts/fetch-crates.sh` 走 curl 预下载。
- 理由：C 盘紧张 + 本机对 crates.io 的 TLS 会被重置（curl 正常，cargo 稳定失败），只有换镜像 + 预下载能稳定构建。
- 状态: 已定

## D11 VS Code 通过"任务 + 调试配置"接入

- 选择：`launch.json` 用 node-terminal 跑 `pnpm tauri dev`（一条配置等于一个运行按钮）；`tasks.json` 放 dev/build/db 统计；`settings.json` 注入 Rust 三个环境变量。
- 理由：用户"希望能直接用上 VSC 的运行按钮"；且 VS Code 进程可能持有旧的环境变量快照。
- 状态: 已定
