# index — 记忆台账

> 用途：记录 MEMORY 下每个文件的分工，以及"每次整理到哪天"，便于下次核账。
> 不写什么：不写章节链接（检索靠 grep + IDE 大纲）；不写正文内容。
> 更新方式：追加台账行（一行 = 一次整理）。

## 文件分工

| 文件 | 放什么 |
|---|---|
| facts.md | 现在是什么样：代码结构地图 + 功能手册（就地重写） |
| decisions.md | 为什么这么定：背景/选项/选择/理由（追加，未定标 待定） |
| lessons.md | 坑与多轮瓶颈：症状→根因→修法→预防 + 未解决项（追加） |
| dev_logs.md | 过程与证据：怎么做的、验证了什么（追加） |
| tmp/{YYYY-MM-DD}.md | 素材流：每轮追加的原始卡片（只追加） |
