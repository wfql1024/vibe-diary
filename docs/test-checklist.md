# 手工测试清单

> 每条写成「怎么做 → 应该看到什么」。启动：`pnpm tauri dev`（或 VS Code 里 `Ctrl+Shift+B`）。
> 下文用「标签A / 标签B / 聚合标签」这类占位名，换成你库里任意两个标签即可。

## 0 环境自检

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 0.1 | 启动后看顶部统计 | `N 条记录 · M 个标签 · K 条标签关系`，没有红色「数据库错误」条 |
| 0.2 | 滚动记录列表 | 按日期倒序，每条下方有标签 chips 和 `＋ 标签` |
| 0.3 | 点右上「标签画布」 | 标签排布成铺满画布的椭圆，工具条显示 `自适应分布：开` 与 `N 个标签 / K 条关系线` |

## 1 标签管理 · 增 / 改名 / 删

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 1.1 | 标签管理 → 输入 `测试标签A` → 添加 | 多出一行「测试标签A 0 条」 |
| 1.2 | 再添加一次同名 | 红色提示「已存在，不能重复创建」，列表仍只有一行 |
| 1.3 | 把 `测试标签A` 改名成库里已有的标签 | 弹「名称已被占用，要合并吗」，可选 合并 / 取消 |
| 1.4 | 选合并 | 原标签消失，记录引用改挂到目标标签，目标标签条数相应增加 |
| 1.5 | 删一个有记录的标签 | 确认框写明会影响多少条记录；确认后记录仍在，只是不再有这个标签 |

## 2 记录的标签编辑

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 2.1 | 任取一条记录点标签上的 `×` | 该标签从这条记录消失；顶部记录数不变；侧栏该标签条数 -1 |
| 2.2 | 点 `＋ 标签` 输入库里已有的标签 | 出现 chip；侧栏该标签 +1 |
| 2.3 | 输入一个库里没有的名字 | 自动创建，标签管理与画布都能看到 |
| 2.4 | 重启应用 | 上述改动都还在 |

## 3 搜索框与筛选

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 3.1 | 点侧栏某个标签 | 搜索框变成 `tag:该标签`，列表上方显示命中数，且**等于该标签上显示的总数** |
| 3.2 | 再点一次同一个标签 | `tag:` 被移除，回到全部记录 |
| 3.3 | 依次点几个不同标签 | 每次命中数都不同（不应出现"点谁都一样"） |
| 3.4 | 敲 `tag:不存在的标签` | 命中 0 条，不报错 |
| 3.5 | 敲 `tag:标签A 关键字` | 标签与文字同时满足，条数不多于只敲 `tag:标签A` |
| 3.6 | 敲两个 `tag:` | 两者同时具备（AND） |

## 4 标签画布 · 关系

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 4.1 | 连线模式，从 `标签A` 拖到 `标签B` | 出现带箭头的线，箭头指向 `标签B`；关系数 +1 |
| 4.2 | 反向再拖一次（B → A） | 合并成一条**双线**，无箭头 |
| 4.3 | 点这条双线 | 确认框显示 `A ↔ B`；删除后两个方向一起消失 |
| 4.4 | 拖到空白处 / 拖到自己身上 | 不产生关系 |
| 4.5 | 建三条互相指向的边（成环） | 能建、不报错，检索不会卡死 |

## 5 检索是否用上关系（重点）

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 5.1 | 建 `标签A → 标签B` | 侧栏 `标签B` 上出现蓝色 `(自身+外部)`；总数 > 自身 |
| 5.2 | 点 `标签B` | 命中数 = 该标签显示的总数 |
| 5.3 | 删掉这条关系再点 `标签B` | 命中数回落到"自身"那个数 |
| 5.4 | 反向建 `标签B → 标签A`，分别搜两者 | 方向单向：只有被指向的一方会带出对方记录 |
| 5.5 | 传递性：`标签A → 标签B → 标签C`，搜 `标签C` | 三者记录都出现；同一条记录只出现一次 |
| 5.6 | 造一个环（A→B、B→A）后搜 A | 不卡死、不重复计数 |
| 5.7 | 关系建好后打开一条只打 `标签A` 的记录 | 它的 chips 里**不会**自动多出 `标签B` |

## 6 画布 · 排布与动画

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 6.1 | 首次进入画布 | 节点从中心附近散开，约 1~3 秒后停住（有过渡动画） |
| 6.2 | 停下后盯几秒 | 完全静止，不会缓慢旋转或蠕动 |
| 6.3 | 整体看 | 铺满画布成横向椭圆；圆的大小随记录数变化 |
| 6.4 | 看相连的两个标签 | 之间始终留出可见的一段线（不会被箭头吃没），且明显比隔跳的近 |
| 6.5 | 建两组互不相干的关系 | 两团之间有肉眼可见的空档 |
| 6.6 | 关闭「自适应分布」→ 移动模式拖动 | 可自由摆放并记住位置；重新打开自适应会平滑回到自动排布 |

## 7 线的避让

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 7.1 | 让一条线从别的圆旁边经过 | 线会弯曲绕开，不会从圆后面消失 |
| 7.2 | 建 4 条互相交叉的关系 | 几秒内交叉自己解开，最终没有两条线交叉 |
| 7.3 | 线靠得很近时 | 两条线保持间距，不会贴在一起 |
| 7.4 | 悬停 / 点击线 | 有 `A → B` 提示；点击弹删除确认 |

## 8 回归 / 边界

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 8.1 | 搜索框输入 `2025-12` | 按日期命中 |
| 8.2 | 搜索框输入不存在的词 | 命中 0 条，列表空态提示 |
| 8.3 | 清空搜索 | 回到最近若干条 |
| 8.4 | 记一笔（带 2 个标签） | 立刻出现在列表顶部，标签正确，统计 +1 |
| 8.5 | 关窗口再启动 | 数据、标签、关系、画布位置全部保留 |
| 8.6 | `node scripts/import-json.mjs --path <导出.json> --dry-run` | 只打印统计，不写库；重复导入不重复插入 |

## 9 已知限制（不算 bug）

- 标签里显示的是 `总数(自身+外部)`，与"直接打标条数"不同，差值是外部带出的部分。
- 关系是无限制传递闭包：长链可能让精确标签带出很多记录。
- 列表一次最多显示 300 条（超出会在标题提示）。
- 画布是固定网格 + 你的拖拽位置，没有自动避让特殊形状。
