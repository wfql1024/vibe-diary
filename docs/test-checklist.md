# 手工测试清单

> 每条写成「怎么做 → 应该看到什么」。启动：`pnpm tauri dev`（或 VS Code 里 `Ctrl+Shift+B`）。
> 下文用「标签A / 标签B / 聚合标签」这类占位名，换成你库里任意两个标签即可。

## 0 环境自检

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 0.1 | 启动后看顶部统计 | `N 条记录 · M 个标签 · K 条标签关系`，没有红色「数据库错误」条 |
| 0.2 | 滚动记录列表 | 按日期倒序，每条下方有标签 chips 和 `＋ 标签` |
| 0.3 | 点右上「标签画布」 | 标签排布成铺满画布的椭圆，工具条显示 `自适应分布：开` 与 `N 个标签 / K 条关系线` |

## 5 检索是否用上关系（重点）

| # | 怎么做 | 应该看到什么 |
|---|---|---|
| 5.1 | 建 `标签A → 标签B` | 侧栏 `标签B` 上出现蓝色 `(自身+外部)`；总数 > 自身 |
| 5.2 | 点 `标签B` | 命中数 = 该标签显示的总数 |
| 5.3 | 删掉这条关系再点 `标签B` | 命中数回落到"自身"那个数 |
| 5.4 | 反向建 `标签B → 标签A`，分别搜两者 | 方向单向：只有被指向的一方会带出对方记录 |
| 5.5 | 传递性：`标签A → 标签B → 标签C`，搜 `标签C` | 三者记录都出现；同一条记录只出现一次 |
| 5.6 | 造一个环（A→B、B→A）后搜 A | 不卡死、不重复计数 |
| 5.7 | 关系建好后打开一条只打 `标签A` 的记录 | 它的 chips 里**不会**自动多出 `标签B` |

## 9 已知限制（不算 bug）

- 标签里显示的是 `总数(自身+外部)`，与"直接打标条数"不同，差值是外部带出的部分。
- 关系是无限制传递闭包：长链可能让精确标签带出很多记录。
- 列表一次最多显示 300 条（超出会在标题提示）。
- 画布是固定网格 + 你的拖拽位置，没有自动避让特殊形状。
## 10 画布：圆面积 / 入场 / 交叉兜底（新增）

| 10.1 | 进入标签画布 | 节点**分批出现**（先大的、连带它的邻居），约 1~2 秒铺满，而不是一次性弹出 |
