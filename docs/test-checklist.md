先找一组好观察的数据：

```bash
node -e "const{DatabaseSync}=require('node:sqlite');const d=new DatabaseSync(process.env.APPDATA+'/com.peekode.vibeDiary/vibe-diary.db');console.log(d.prepare('SELECT t.name, COUNT(et.entry_id) c FROM tags t LEFT JOIN entry_tags et ON et.tag_id=t.id GROUP BY t.id ORDER BY c ASC LIMIT 10').all())"
```

| # | 怎么做 | 应该看到什么 |
|---|---|---|

## 8. 已知限制（不算 bug）

- 侧栏黑字是「直接打标条数」，与检索命中数的差值是蓝字 `+N`。
- v2 迁移之前画的箭头方向可能被旧约束反转过，方向不对就删掉重画。
- 列表最多显示 300 条（超出时提示「仅显示前 300 条」）。
- 画布是固定网格 + 你的拖拽位置，没有自动避让/重新排布。
